# Opened Circle

A mobile app built with [Expo](https://expo.dev) + React Native + TypeScript.

## Getting started

```bash
npm install
npm start
```

Then press `i` for iOS simulator, `a` for Android emulator, or scan the QR code with the Expo Go app on your phone.

## Project structure

- `App.tsx` — app entry point
- `assets/` — icons, splash images, etc.
- `designs/` — design files (mockups, exports) used as reference for building screens
